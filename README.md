# Python 練習與學習指南

這個工作區用來循序學習 Python。可以依照目前想練的方式提出要求；出題時會先確認難度，並依照學習進度安排內容。

## 練習方式

| 方式 | 內容 | 可以這樣說 |
|---|---|---|
| 學新語法 | 先用簡短、不同情境的例子教新概念，再做一題基礎練習。 |「教我一個新的 Python 語法並出題」|
| 複習 | 練習已學過的語法，鞏固觀念。 |「出一題複習題」|
| 綜合應用 | 將多種已學語法組合在同一題中。 |「出一題綜合題」|
| 小專案 | 將多個概念用在較完整的小程式中。 |「給我一個小專案練習」|
| 除錯 | 閱讀有問題的程式，找出錯誤並嘗試修正。 |「出一題除錯練習」|
| 檢查作業 | 檢查自己完成的練習，獲得正確處與改善提示。 |「幫我檢查 exercise_14.py」|

## 難度

出新題目時會先詢問難度；也可以在要求中直接指定：

- **簡單**：少量、較基礎的概念。
- **普通**：組合幾種已學過的語法。
- **困難**：使用較多已學語法，完成較完整的任務。

例如：「出一題**困難**的**綜合應用**。」

練習方式和難度是不同選項，例如可以選「簡單的複習題」或「普通的小專案」。若題目需要尚未建立的先備概念，會先教學或安排基礎練習，不會預設已經學會。

## 練習檔案

- [`new_exercises/`](./new_exercises/)：尚未完成或尚未檢查通過的題目。
- [`practiced/`](./practiced/)：已完成並檢查通過的題目。
- 題號跨兩個資料夾共用並依序增加，例如 `exercise_31.py` 之後接續 `exercise_32.py`。
- 每題會建立獨立的 Python 檔案；檔案開頭包含教學和題目說明，預設不提供完整答案。
- 完成並檢查通過後，題目會從 `new_exercises/` 移到 `practiced/`。
- [python_learning_progress.md](./python_learning_progress.md) 記錄已練習、尚未確認熟練和已出題的概念；出題會參考這份進度。

## 學習建議

1. 選擇想練習的方式和難度，或直接要求出題。
2. 先閱讀新題目檔中的教學，再自己完成題目。
3. 請求檢查時，指出題目編號或檔案；優先使用提示自行修正。
4. 檢查通過後，題目會整理到 `practiced/`。
